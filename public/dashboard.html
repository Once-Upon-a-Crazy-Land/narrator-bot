Discord sign-in setup required

In the Narrator Railway service, set DISCORD_CLIENT_SECRET to the Narrator application's OAuth2 client secret and DASHBOARD_URL to https://narrator.crazyland.art. Keep the existing CLIENT_ID.

In that application's Discord Developer Portal OAuth2 settings, add this redirect:

https://narrator.crazyland.art/auth/callback

Redeploy after saving the variables, then reload this page.
